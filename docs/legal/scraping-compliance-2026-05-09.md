# Phase 5c スクレイピング適合性調査レポート

**作成日**: 2026-05-09  
**対象機能**: Phase 5c イベント目標逆算（ランキング取得・自動集計）  
**調査対象**: ふわっち (whowatch.tv) / ニコ生 (live.nicovideo.jp)  
**調査者**: Phase 5c 利用規約適合性調査エンジニア

---

## 1. 調査概要

Phase 5c で実装予定の「イベント一覧取得・ランキング自動取得」機能の法的適合性を事前調査。
各プラットフォームの robots.txt・利用規約・禁止行為規定を参照し、スクレイピングに関する条項を抽出・評価する。

---

## 2. ふわっち (whowatch.tv)

### 2-1. robots.txt 調査

**URL**: `https://whowatch.tv/robots.txt`  
**取得日**: 2026-05-09

**Disallow 対象パス（全 User-agent）**:
```
Disallow: /live-achievements
Disallow: /viewer/
Disallow: /sp/viewer/
Disallow: /points/
```

**注目点**:
- `/events/` `/ranking/` はDisallow未記載 → クローラーアクセス拒否なし
- `User-agent: Bingbot` に `Crawl-delay: 10` 設定あり（一般 UA への crawl-delay 指定なし）
- `User-agent: *` セクションに delay 指定なし

**評価**: イベント・ランキングページへのアクセスは robots.txt 上は非制限。

### 2-2. 利用規約 調査

**URL**: `https://whowatch.tv/terms-of-service.html`  
**取得日**: 2026-05-09

**スクレイピング関連条項（抜粋）**:

| 条項 | 内容 | スクレイピングへの適用可能性 |
|------|------|---------------------------|
| 第8条(12) | 当社サービスを技術的に解析・改変する行為 | 「技術的解析」として広義解釈される余地あり |
| 第8条(13) | 当社サービスを複製、頒布、譲渡、貸与する行為 | 表示データの複製として解釈可能だが限定的 |

**明示的な禁止なし**:
- 「クローラー」「ボット」「スクレイピング」「自動アクセス」「API」等の直接的言及なし
- 禁止事項ヘルプページにもクローラー・自動ツールの記載なし

### 2-3. 実態調査（第三者事例）

以下の第三者サービスがふわっちを継続的にスクレイピングしており、法的措置の事例は確認されていない:

- `ikioi-ranking.com` — 配信者勢いランキング（ふわっちデータ参照）
- `mix.live-ranking.com` — マルチプラットフォームランキング
- `chikuwachan.com` — ふわっち専門ランキング

### 2-4. リスク評価

**判定: (b) 曖昧**

**根拠**:
- 明示的なスクレイピング禁止条項は存在しない
- 第8条(12)「技術的に解析する行為」の適用範囲が不明確
- robots.txt はイベント・ランキングページを非制限
- 複数の第三者ランキングサービスが常時スクレイピングを実施し、事業者による明示的停止・警告事例なし
- ただし、サーバー負荷を与える過度なアクセスは禁止行為(第8条 一般項)に該当しうる

**軽減条件**:
1. User-Agent に識別情報を含める（例: `TagDeck/0.1 (+https://tagdeck.jp)`）
2. アクセス間隔 25秒以上を維持（Phase 5a 実装済みの制限を継承）
3. イベント期間中のランキングページのみアクセス、不要期間は停止
4. `/viewer/` `/points/` 等 Disallow 対象パスは一切アクセスしない

## 3. ニコ生 (live.nicovideo.jp)

### 3-1. robots.txt 調査

**URL**: `https://live.nicovideo.jp/robots.txt`  
**取得日**: 2026-05-09

```
User-agent: *
Allow: /
```

**評価**: 全パスをクローラーに開放。制限一切なし。

### 3-2. 利用規約 調査

#### ニコニコ利用規約（共通）

**URL**: `https://account.nicovideo.jp/rules/account`  
**取得日**: 2026-05-09

**スクレイピング関連条項（抜粋）**:

| 条項 | 内容 | 適用可能性 |
|------|------|----------|
| 第5条 | ニコニコのサーバーに過度の負担を及ぼす行為 | 過度なアクセス頻度への制限として機能する可能性あり |
| 第6条 | その他ニコニコが不適切と判断する行為 | 包括条項。判断基準が不明確 |

**明示的な禁止なし**:
- 「スクレイピング」「クローラー」「ボット」「自動アクセス」の直接記載なし

#### ニコ生利用規約

**URL**: `https://site.live.nicovideo.jp/rule.html`  
**取得日**: 2026-05-09

ニコニコ共通規約第5・6条を参照する形式。ニコ生固有のスクレイピング禁止規定はなし。

### 3-3. 非公開 API 廃止事例

ドワンゴは2022年に非公開 API (旧ニコ生 API) を廃止。廃止告知には「ニコニコ外からご利用の形跡がありました」との記述があり、外部からの API 利用を認識していた。ただし、廃止という手段で対応したのみで、法的措置・警告状の送付などは確認されていない。

GitHub `niconicolibs/api` リポジトリ（非公式 API ドキュメント）が公開状態で存在し、ドワンゴから削除要求は受けていない。

### 3-4. リスク評価

**判定: (b) 曖昧**

**根拠**:
- robots.txt は `Allow: /` で完全開放
- 利用規約に明示的スクレイピング禁止なし
- 「過度な負荷」という曖昧な基準のみ
- 公式 API が廃止済みのため、データ取得にはスクレイピング以外の手段が実質存在しない
- 第三者開発者による非公式 API ドキュメントが公開・容認されている

**軽減条件**:
1. アクセス間隔 30秒以上（公式 API の標準 rate limit 相当）
2. User-Agent に識別情報を付与
3. ページ全体ではなくランキング表示部分のみ取得
4. キャッシュを活用し、不要な繰り返しアクセスを排除

## 5. Phase 5c-β 着手判断

### 判断: **条件付き着手可 (Go with conditions)**

両プラットフォームとも「(b) 曖昧」判定であり、明示的な禁止はない。以下の実装条件を遵守することで、現時点では許容可能なリスク範囲に収まると判断する。

### 必須遵守条件

| # | 条件 | 実装場所 |
|---|------|---------|
| 1 | アクセス間隔: ふわっち 25秒以上、ニコ生 30秒以上 | polling ロジック |
| 2 | User-Agent: `TagDeck/0.1 (+https://tagdeck.jp)` 固定 | HTTP クライアント共通設定 |
| 3 | robots.txt の Disallow パスへのアクセス禁止 | fuwacchi-ranking.ts 実装済み継承 |
| 4 | イベント期間外は自動停止（polling は開催中のみ） | event status 判定 |
| 5 | キャッシュ活用により同一データの重複取得を排除 | TanStack Query staleTime |
| 6 | スクレイピング対象は表示ランキングデータのみ（個人情報等は除外） | パーサー実装範囲制限 |

### 継続監視項目

- ふわっち ToS が改訂され「クローラー禁止」等の明示条項が追加された場合は即停止
- ふわっち/ニコニコから cease-and-desist や警告メールを受信した場合は即停止
- 月1回 robots.txt の変更確認を実施

### ニコ生 MVP 推奨方式

公式イベント API が廃止済みのため、以下を推奨:
1. **MVP**: ユーザーが手動でランキング URL を貼り付け → HTML スクレイピング
2. **将来**: 非公式 API エンドポイント調査（Phase 5c-β 実装中に検証）
